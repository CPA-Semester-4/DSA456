# Heaps/Binary Heaps

A tree based data structure that satisfies <b>`heap property`</b>. Binary heap is an implementation of `Priority Queue`

<b> Heap Properties: </b>
- Complete Binary tree
- Order - For each node parent node must have a higher priority

## Operations on Binary Heap
<b> Node </b> -> `left child = 2n + 1` | `right child = 2n + 2`

### Insert - add an item to the binary heap


### Delete - remove an item with the highest priority in the binary heap

### Heapify - (n-1/2)
